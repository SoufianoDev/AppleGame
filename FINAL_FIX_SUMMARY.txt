================================================================================
                         WHY THIS MATTERS
================================================================================

Godot-Kotlin/JVM Export Flow:

  Source Files (.tscn)
         ↓
    [Parse & Compile]
         ↓
  .godot/exported/ cache (compiled binary scenes)
         ↓
    [Export to APK]
         ↓
  Android APK (contains .scn files with hardcoded paths)

KEY POINT: The APK uses the CACHED scene files, not source files!

If cache has wrong paths → APK has wrong paths → Assets won't load → Hang
